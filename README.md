# Калькулятор свободного времени

Веб-сайт, на котором можно составить типичную неделю и увидеть, сколько времени занято сном, работой, учёбой, другими делами и дорогой, а сколько остаётся свободным. Проект также служит основой для учебного кейса по продуктовой аналитике на реальных обезличенных данных.

## Текущее состояние

Этап 1 завершён: зафиксированы [описание продукта](docs/product-brief.md), [правила расчёта](docs/calculation-rules.md) и [визуальные концепции](design/concepts.md). Пользователь выбрал G3 «Карточки дней»; на её основе создана [дизайн-система](docs/design-system.md). Клиентский MVP реализован; следующий этап — самостоятельное проектирование метрик и событий.

## Запуск и проверка

Нужны Node.js 20.19+ и pnpm. В корне проекта выполните:

```bash
pnpm install
pnpm dev
```

Откройте адрес, который покажет Vite. Для проверки расчёта и сборки используйте `pnpm test` и `pnpm build`. Короткие браузерные проверки запускаются командой `pnpm test:e2e` при работающем сайте на `http://127.0.0.1:5173`. Playwright нужен доступный Chromium; на Windows можно использовать установленный Edge через переменную окружения `PLAYWRIGHT_CHANNEL=msedge`.

Расписание сохраняется в localStorage текущего браузера и удаляется кнопкой «Очистить расписание». Сервер, аккаунты и сбор аналитических событий пока не подключены.

## Принцип работы с аналитикой

Пользователь проекта самостоятельно определяет метрики и события, пишет SQL, исследует данные, формулирует выводы и гипотезы. Помощь на этих этапах — объяснение подхода и проверка решений. Точное расписание должно обрабатываться в браузере; будущая аналитика может получать только согласованные необходимые события и агрегаты без персональных данных.

## Ближайшие этапы

1. Продукт и дизайн — готово.
2. Клиентский MVP — готово.
3. [Самостоятельно определить метрики и события](docs/analytics-workshop.md), затем пройти ревью определений.
4. По согласованной схеме добавить сбор событий и PostgreSQL.
5. Опубликовать сайт и проверить качество первых реальных данных.

Следующие технические этапы зависят от вашего решения на этапе 3.
