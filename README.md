# Калькулятор свободного времени

Веб-сайт, на котором можно составить типичную неделю и увидеть, сколько времени занято сном, работой, учёбой, другими делами и дорогой, а сколько остаётся свободным. Проект также служит основой для учебного кейса по продуктовой аналитике на реальных обезличенных данных.

## Текущее состояние

Этап 1 завершён: зафиксированы [описание продукта](docs/product-brief.md), [правила расчёта](docs/calculation-rules.md) и [визуальные концепции](design/concepts.md). Пользователь выбрал G3 «Карточки дней»; на её основе создана [дизайн-система](docs/design-system.md). Следующий этап — клиентский MVP.

## Принцип работы с аналитикой

Пользователь проекта самостоятельно определяет метрики и события, пишет SQL, исследует данные, формулирует выводы и гипотезы. Помощь на этих этапах — объяснение подхода и проверка решений. Точное расписание должно обрабатываться в браузере; будущая аналитика может получать только согласованные необходимые события и агрегаты без персональных данных.

## Ближайшие этапы

1. Продукт и дизайн: правила расчёта, визуальные концепции, выбранная дизайн-система.
2. Клиентский MVP: ввод недели и проверенный расчёт свободного времени.
3. План аналитики: самостоятельное определение метрик и событий.
4. Сбор событий: backend и PostgreSQL по утверждённой схеме.
5. Публикация, проверка качества первых данных и самостоятельный анализ.

Подробный roadmap согласован отдельно; следующие этапы зависят от результатов предыдущих.
