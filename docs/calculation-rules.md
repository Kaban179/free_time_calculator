# Правила расчёта MVP

Этот документ фиксирует техническое поведение калькулятора. Неделя типичная и повторяется без календарных дат; начало недели — понедельник. Все вычисления ведутся в целых минутах.

## Ввод

- Одна запись задаёт категорию, выбранные дни, время начала и окончания. Категории: сон, работа, учёба, быт, здоровье, отдых, другое. Для категорий кроме сна можно указать название и формат online/offline.
- Для offline можно указать длительность дороги туда и обратно от 0 до 240 минут каждая. Для online и сна дорога равна нулю; при переключении на online прежние значения дороги сбрасываются.
- Хотя бы один день должен быть выбран. Равные начало и конец недопустимы. Если конец раньше начала, запись заканчивается на следующие сутки; длительность записи всегда меньше 24 часов.
- Для обычных активностей выбранный день — день **начала активности**. Для сна, который проходит через полночь, выбранный день — утро, когда человек просыпается: сон 23:00–07:00 для вторника начинается вечером в понедельник. Дорога туда начинается непосредственно перед активностью, дорога обратно — сразу после неё. Поэтому часть интервала может попасть на соседний день.

## Занятость и конфликты

- Каждая выбранная запись повторяется раз в неделю. Интервалы, переходящие границу воскресенья и понедельника, учитываются как часть непрерывной повторяющейся недели.
- Минуты сна и самих активностей относятся к их категориям; минуты дороги относятся только к категории «Дорога». Каждый интервал делится на границе суток, поэтому дневные итоги отражают фактические минуты в этом дне.
- Если ни один из пересекающихся интервалов не относится к онлайн-занятию, пересечение считается ошибкой. Сон сам по себе не считается онлайн-занятием. Если хотя бы одно занятие действительно онлайн, пересечение допустимо, в том числе с дорогой или сном. Такие блоки выделяются жёлтым. Соприкасающиеся границы пересечением не считаются.
- Недопустимое пересечение проверяется сразу при сохранении: запись остаётся в форме до исправления времени или дня. Если старое сохранённое расписание уже содержит конфликт, при расчёте показывается только первая ошибка.
- Совмещённая минута считается занятой только один раз. В распределении категорий приоритет имеет офлайн-занятие, сон или дорога; онлайн-занятие получает только минуты, не занятые ими. Если пересекаются два онлайн-занятия, общие минуты получает первое добавленное. Поэтому сумма категорий остаётся равной 168 часам вместе со свободным временем.
- Внутри одной offline-записи дорога туда, активность и дорога обратно следуют подряд и не конфликтуют друг с другом.

## Результат

- Свободное время дня = 1440 минут минус сумма его непересекающихся занятых интервалов. Недельное свободное время — сумма семи дневных значений; занятое + свободное = 10080 минут.
- Показываются занятое и свободное время каждого дня и недели, а также минуты по категориям. Дорога — отдельная категория. В графике структуры всей недели свободное время показывается отдельно, чтобы сумма категорий равнялась 168 часам.
- После изменения расписания прежний результат помечается устаревшим до нажатия «Рассчитать неделю»; ошибка ввода не удаляет записи и не подменяет прежний итог новым.
- Если повторяющееся занятие открыто из конкретного дня, изменение или удаление касается только этого дня. Новый сон для дня заменяет прежний сон этого дня, не создавая второй блок.

Точное расписание хранится только в браузере устройства для восстановления после обновления страницы. Пользователь может очистить его. На сервер и в будущие аналитические события точные интервалы и названия активностей не передаются.
